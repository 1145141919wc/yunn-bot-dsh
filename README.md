# yunn-bot-dsh
机器人专用协助

## 使用说明

在飞书群中 `@机器人` 并说明需求即可。机器人会自行读取对话、查询仓库或修改代码；涉及代码改动时，会以 Pull Request 的形式提交，不会直接修改主分支。

### 示例 1：直接问答

> @机器人 这个仓库是做什么的？

机器人直接回复，适合确认信息或快速提问。

### 示例 2：让机器人修改仓库

> @机器人 在仓库 README 里加一节「使用说明」，写三条使用示例

机器人会新建分支、修改文件并提交 Pull Request，完成后把 PR 链接回复到群里。

### 示例 3：汇总仓库动态

> @机器人 汇总一下仓库最近的 Pull Request 和 CI 状态

机器人会读取 Pull Request、检查结果并给出摘要。

> 提示：只有 @机器人 的消息才会触发任务，普通聊天消息不会被处理。
